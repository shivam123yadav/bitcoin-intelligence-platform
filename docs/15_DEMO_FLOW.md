# 15 --- SIH Demo Flow

## Recommended demonstration

### 1. Dataset

Open Dataset Management.

Show: - dataset registration - validation - record counts - data-quality
summary

### 2. Analysis

Start an analysis run.

Show: - ingestion - validation - normalization - GeoIP enrichment -
correlation - graph construction - feature engineering - anomaly
detection - clustering - pattern analysis - prioritization -
explainability

### 3. Leads

Open Investigative Leads.

Show ranked leads and filtering.

### 4. Entity

Open one lead.

Show: - anomaly score - priority - evidence - timeline - related
wallets/IPs

### 5. Graph

Open the entity in Graph Investigation.

Show: - IP - transaction - wallet - relationship edges - selected-node
evidence

### 6. Transaction flow

Show a candidate transaction sequence and its evidence.

### 7. Cluster

Show the associated behavioral/graph cluster.

### 8. Case/report

Create or assemble an investigation case and export a report.

## Demo language

Say: - "flagged for review" - "model identified an anomaly" - "candidate
pattern" - "observed relationship" - "evidence links the observation to
these records"

Do not say: - "this wallet is criminal" - "the model proves
laundering" - "this transaction is definitely illicit"
