# 01 --- Project Overview

## Product

**Bitcoin Intelligence --- Transaction Monitoring & Investigation
Platform**

## Problem

The platform analyzes bulk Bitcoin transaction and network metadata
offline to help analysts identify unusual behavior, relationships, and
transaction-flow patterns.

## Core investigative questions

The system should help answer: - Which entities exhibit unusual
behavior? - Which transactions are statistically anomalous? - Which
wallets appear related based on observable evidence? - Which IP
observations correlate with transactions or wallet activity? - Which
transaction sequences resemble peeling-chain or mixing-like
structures? - Why was a lead prioritized? - What source observations
support the finding?

## Non-goals

The prototype is not: - a cryptocurrency exchange - a live blockchain
explorer - a Bitcoin node - a live network interception system - a
criminality classifier - a replacement for human investigation

## Output terminology

Use: - investigation lead - investigation priority - anomaly score -
model finding - observed association - candidate pattern - potential
pattern - evidence

Avoid: - criminal wallet - confirmed launderer - confirmed illicit
transaction - proof of criminal activity
