# 14 --- Reporting

## Goal

Produce a concise investigative report from selected leads/cases.

## Report contents

-   report ID
-   analysis run
-   dataset
-   generation timestamp
-   selected entities
-   priority
-   anomaly/model findings
-   graph relationships
-   transaction-pattern findings
-   evidence/source references
-   analyst notes

## Evidence principle

Every important conclusion in the report should point to observable
source data or a clearly identified derived/model finding.

## Export

PDF generation may be implemented locally.

No cloud document-generation service is required.
